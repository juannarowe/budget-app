# IT Budget App

Aplicación web para generar y gestionar presupuestos de servicios digitales (SEO, Ads, Web).

**Demo:** https://itbudgetapp.netlify.app/

## Funcionalidades

- Selección de servicios con precio dinámico
- Configurador de páginas e idiomas para el servicio Web
- Formulario de cliente con validación
- Lista de presupuestos con búsqueda y ordenación
- Página de detalle por presupuesto
- Descarga en PDF y compartir por URL
- Persistencia en `localStorage`

## Tecnologías

- React 19 + TypeScript
- React Router v7
- jsPDF
- Vite

## Desarrollo local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
